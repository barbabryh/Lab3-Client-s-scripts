# Лабораторная работа №3 — Доска публикаций

## Запуск
Открыть файл index.html в браузере.

## Реализовано
- Кнопка «Загрузить публикации»: GET-запрос на https://jsonplaceholder.typicode.com/posts?_limit=5 через fetch и async/await, проверка response.ok, вывод 5 публикаций через DOM.
- Форма «Заголовок» и «Текст»: проверка на пустые значения (после trim), POST-запрос с JSON {title, body, userId: 1} и заголовком Content-Type: application/json, вывод заголовка и ID из ответа.
- Сообщения «Загрузка...» и «Отправка...», обработка ошибок через try/catch/finally, кнопка снова активна после ошибки.

## Результаты проверки
- Загрузка: появляются 5 публикаций
- Пустые поля или пробелы: ошибка, запрос не отправляется
- Корректные данные: публикация появляется на странице с ID (HTTP 201)
- Адрес /postz (404): показывается ошибка, кнопка снова работает; адрес восстановлен
